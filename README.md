# 🎨 Advanced CSS — Portfolio

A responsive personal portfolio page built from scratch using advanced CSS techniques. Showcases past work with a featured-project layout, a fixed navigation bar, and a polished design that adapts cleanly from desktop to mobile — no frameworks, no JavaScript.

---

## 📖 Overview

This project is an exercise in writing professional CSS without relying on utility frameworks. The layout is built with Flexbox and media queries, the color scheme uses CSS custom properties for easy theming, and the work section uses a featured-first card layout that highlights the most important project.

---

## ✨ Features

- 🔝 Fixed **navigation bar** with smooth scroll links to each section
- 👤 **About / hero section** with avatar image and a short bio
- 🖼️ **Work section** — first project card spans the full width; remaining projects share the row below
- 🔗 Project cards are **clickable links** that open the deployed app
- 📱 Fully **responsive** — layout reflows at two breakpoints for tablet and mobile
- 🎨 **CSS custom properties** (`--primary`, `--secondary`, etc.) for consistent theming

## 💡 What I Learned

- Using **Flexbox** to build complex multi-column layouts without a grid framework
- Writing **media queries** to create a genuinely responsive layout at multiple breakpoints
- Leveraging **CSS custom properties** to centralize theme values and make changes once
- Implementing the **featured-first pattern** — making one card visually dominant while keeping the others consistent
- Building a fixed nav that doesn't cover content by accounting for its height in section padding
